How to read this page

Every input the model uses is listed below with the file and cell it came from. Blue cells are inputs you can change. Results compare your scenario with the source data for the same year and method, so every change in dollars shows its effect on funded service, gaps, and unused funds. The rules applied are listed at the end and in RULES.md.
