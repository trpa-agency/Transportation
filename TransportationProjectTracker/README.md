# Transportation Plan Projects

A single-page tool that brings together the project lists from three TRPA plans so you can search them in one place, see which projects appear in more than one plan, and download lists to Excel.

- Connections 2050 Regional Transportation Plan (RTP), Appendix B project list: 135 entries
- 2024 Active Transportation Plan (ATP), Chapter 4 corridor project tables 4-1 to 4-6: 124 projects, checked against the 2024 ATP Proposed Projects map
- Lake Tahoe Region Vision Zero Strategy, candidate project locations: 30 locations

Open `index.html` in a browser to use the tool. It needs an internet connection, because AG Grid (tables), Calcite (buttons), SheetJS (Excel export), and Google Fonts load from public CDNs.

## Folder layout

| Path | What it is |
|---|---|
| `index.html` | The tool. Generated by `build.py`; don't edit it by hand. |
| `build.py` | Combines the plan lists, links matching projects, applies review decisions, and writes `index.html`. |
| `src/template.html` | Page layout, styles, and app code. Edit this to change how the tool looks or works. |
| `data/rtp_project_list.py` | RTP Appendix B rows, transcribed from the PDF. |
| `data/atp_project_tables.py` | ATP Chapter 4 table rows, transcribed from the PDF. |
| `data/atp_map_snapshot.json` | Snapshot of the 2024 ATP map layer (descriptions, facility types, jurisdictions). |
| `data/vision_zero_locations.py` | Vision Zero candidate locations, transcribed from the PDF. |
| `assets/` | TRPA design tokens (`trpa-tokens.css`), logo, and favicon. Embedded into `index.html` at build time. |
| `sources/` | The plan pages the data came from. |

## Making changes

1. Edit the data file, `build.py`, or `src/template.html`.
2. From this folder, run `python build.py`. It needs Python 3 and nothing else.
3. Open `index.html` to check the change.

Add `-v` (`python build.py -v`) to print every group of projects that's linked across plans.

### Where things live

- **A project's values** (name, cost, lead implementer, phase, year): the plan's data file. ATP values come from the plan tables, not the map.
- **ATP projects that are complete:** `COMPLETE` at the bottom of `data/atp_project_tables.py`. ATP projects with no facility on the map are listed in `NOT_ON_MAP` there.
- **Jurisdiction overrides for RTP entries:** `RTP_JUR` near the top of `build.py`.
- **Cross-plan matches:** the "Matching" section of `build.py`. Entries with the same EIP number link automatically. Matches by name or location are listed in `M` (RTP to ATP) and `VZM` (Vision Zero to RTP).
- **Page text, columns, filters, and Excel layout:** `src/template.html`.

## Data notes

- ATP jurisdiction comes from intersecting each mapped line with the TRPA jurisdictions layer (`Boundaries/MapServer/10`). RTP jurisdiction comes from the plan's county column, with entries inside the City of South Lake Tahoe assigned to the city and overrides in `RTP_JUR`. Regional entries apply basin-wide.
- Not every entry lists a cost, so the tool doesn't total costs. Vision Zero locations don't list costs.
- In RTP Appendix B, the illustrative active transportation totals don't equal the sum of their rows: the 2031–2040 total is $1,807,593 lower and the 2041–2050 total is $61,133,808 higher. The Glenbrook Entrance to Round Hill Pines Beach row shows no cost. Other section totals differ from their rows by $1 to $3 from rounding. `RTP_TOTALS` in the RTP data file holds the printed totals.
- A trailing `*` on an RTP title marks a regionally significant project, per the Appendix B footnote on page B-23.
- The ATP map layer cuts descriptions at 500 characters; those end with an ellipsis in the tool.
- All 119 map facilities match an ATP table row. Five table rows aren't on the map: Bijou Bike Park Connector and Apache Avenue Complete Streets (complete), Alta Mira Public Access Improvements (deferred), TCPUD Multi-Use Trail System Reconstruction (completion 2028), and Barbara Ave bike route.
- The ATP map snapshot was pulled Oct. 21, 2026. The tool doesn't update itself when the map changes.

## Design

Built with the TRPA design system: the Connecting Tahoe palette and Lexend Deca for the content, with the agency header. Blue fills that carry white text use #2273A3, not #2B94D1, to meet WCAG AA contrast. The multi-plan highlight uses gold because red is the Vision Zero plan color. Check accessibility (contrast, keyboard use, labels) after any design change.

## Publishing

To publish with GitHub Pages from the Transportation repository, turn on Pages for the repository (Settings > Pages, deploy from the main branch, root folder). The tool's address will end in `/TransportationProjectTracker/`. Anything in this folder, including `sources/`, is public once the repository is.
