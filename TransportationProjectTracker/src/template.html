About this tool

This tool brings together the project lists from three TRPA plans so you can search them in one place, see where they overlap, and take a list with you in Excel. Each row is a plan entry: a project as it appears in one plan. A project that appears in two plans shows up as two linked rows.

Plans and sources

  • Connections 2050 Regional Transportation Plan (RTP), Appendix B project list: 135 entries on the foreseeable (constrained) and illustrative (unconstrained) lists, in five categories. Costs are shown as the plan lists them for 2025 to 2030, 2031 to 2040, and 2041 to 2050.
  • 2024 Active Transportation Plan (ATP), Chapter 4 corridor project tables 4-1 to 4-6: 124 projects with priority tiers. Each one is checked against the 2024 ATP Proposed Projects map, which adds descriptions, facility types, and locations. Two projects in the tables are complete and are marked Complete.
  • Lake Tahoe Region Vision Zero Strategy, candidate project locations (pages 47 to 49): 30 locations, eight of them priority projects.

Data in this file is a snapshot taken __BUILT__. The tool doesn't update itself when the plans or the map change.

How projects are matched across plans

  1. Same EIP project number. The RTP entry and the ATP facility carry the same Environmental Improvement Program (EIP) number.
  2. Same project, matched by name and limits. The entries have no shared number but describe the same project and termini.
  3. Same location and limits. A Vision Zero location covers the same corridor and limits as an RTP project.
  4. Listed as a connection. The Vision Zero Strategy names the RTP project under connections to existing plans and projects.

Each project's detail panel shows which of these applies. Matches 2 through 4 were made by hand and are worth a second look before you rely on them.
